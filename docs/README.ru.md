**Разработчик:** [APTOFI.COM](https://aptofi.com)

Закончилось место в Google Drive, Яндекс Диске или другом облаке, но есть свободный HDD/SSD и Windows‑ПК с сетью? **APTOFI File Sharing превращает этот компьютер в собственный файлообменник.**

## Сильные стороны

- свои диски вместо платного облачного места;
- перетаскивание папок целиком с автоматическим созданием всей иерархии и пустых подпапок;
- возобновляемая потоковая загрузка больших файлов после обрывов;
- скачивание папки или выбранных мышкой объектов одним потоковым ZIP64 без временного полного архива;
- отдельные пользователи, квоты, IP последнего входа, публичные ссылки и полное удаление пользователя с его данными;
- корзина опциональна и по умолчанию выключена; при включении хранит удалённое 30 дней и до физического удаления продолжает занимать квоту;
- публичные ссылки с паролем и сроком действия;
- работа по локальной сети, прямому IP/домену или через VPS/reverse SSH tunnel;
- автоматический HTTPS через ACME DNS-01 и RFC2136/TSIG;
- Windows-служба с автозапуском и панель в трее;
- адаптивный WEB для ПК/планшета/телефона, 10 языков.

## Требования и сборка

Для запуска: Windows 7 SP1–Windows 11 и .NET Framework 4.8. Нужны права администратора для службы, HTTP.sys, firewall и сертификатов.

Для сборки: Visual Studio 2022 + **.NET Framework 4.8 Developer Pack**.

```powershell
msbuild APTOFI.FileSharing.sln /m /restore /p:Configuration=Release /p:Platform="Any CPU"
```

Готовый файл: `src/APTOFI.FileSharing/bin/Release/afsharing.exe`.

## Первый запуск

1. Запусти `afsharing.exe` от администратора.
2. Добавь хранилище, например `D:\FileSharing`.
3. Создай/проверь аккаунт администратора.
4. Обязательно замени секретные пути, например `/my-admin-9F3x` и `/files-k7P2`.
5. Выбери режим сети.
6. Нажми **Сохранить и запустить**.
7. Открой сформированную ссылку пользователя или администратора.

## Только локальная сеть

```text
Локальный IP привязки: 0.0.0.0
Режим: Локальный
HTTP порт: 15745
HTTPS: можно выключить для доверенной LAN
Путь пользователя: /files-k7P2
```

Если ПК сервера имеет IP `192.168.1.50`, открывай:

```text
http://192.168.1.50:15745/files-k7P2
```

Домен не нужен. При необходимости разреши порт в Windows Firewall.

## Чисто по публичному IP

Выбери **Прямой IP**, пробрось TCP-порт роутера на ПК сервера. Публичный HTTP по IP технически возможен при выключенном HTTPS, но для паролей и приватных файлов это небезопасно. Для Интернета лучше использовать домен + HTTPS или VPS/туннель. При CGNAT прямой вход обычно невозможен — используй VPS.

## Домен + HTTPS

Пример настроек для провайдера с RFC2136/TSIG:

```text
Режим: Прямой IP
Домен: files.example.net
HTTPS порт: 15746
Обновление DNS: RFC2136 / TSIG
DNS сервер: ns1.example.net
DNS зона: files.example.net
Имя TSIG-ключа: имя из DNS-провайдера
Алгоритм: HMAC-SHA256
Секрет TSIG: секрет из DNS-провайдера
Автообновление A-записи: включено
Email сертификата: admin@example.net
Условия CA: приняты
```

Сохрани настройки, проверь DNS, выпусти HTTPS-сертификат и пробрось TCP `15746` на сервер. Для DNS-01 публичные порты 80/443 для проверки сертификата не нужны.

### Пример dynv6

```text
Домен: myfiles.dynv6.net
DNS сервер обновлений: ns1.dynv6.com
DNS зона: myfiles.dynv6.net
Алгоритм: HMAC-SHA256
TSIG key name / secret: создать в аккаунте dynv6
```

TSIG-секрет никогда не добавляй в Git.

## VPS / туннель

Если ПК за CGNAT, используй режим **VPS / туннель**. Укажи Ubuntu/Debian VPS, SSH-порт, пользователя, пароль или ключ, удалённый порт и домен. APTOFI поддерживает переподключаемый reverse SSH tunnel.

```text
VPS: 203.0.113.20
SSH порт: 22
SSH пользователь: aptofi
Порт туннеля на VPS: 18080
Домен VPS: files.example.net
```

## Использование

Перетаскивай файлы или целые деревья папок в браузер. В «Свойствах» доступны скачивание, переименование, удаление и перемещение. Несколько объектов можно выделить мышкой и скачать правой кнопкой одним ZIP. Для внешних людей создавай публичные ссылки с паролем/сроком. Квоты настраиваются в админке.

## Безопасность репозитория

Не публикуй `afsharing.settings`, базы, логи с чувствительными данными, TSIG-секреты, SSH-ключи и приватные ключи сертификатов. `.gitignore` уже исключает runtime-данные. Атрибуция проекта явная и описана в лицензии: **APTOFI.COM — https://aptofi.com**.
