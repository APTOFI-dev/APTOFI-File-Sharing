# Contributing

Contributions are welcome. Keep changes focused, readable and compatible with the existing direct architecture.

Before opening a pull request:

1. Build `Release | Any CPU` on Windows with Visual Studio 2022 and the .NET Framework 4.8 Developer Pack.
2. Do not commit runtime databases, settings, secrets, certificates, logs, thumbnails or temporary uploads.
3. Keep all 10 web language dictionaries in sync when adding UI text.
4. Avoid fallback chains that hide errors; make failures diagnosable.
5. Preserve the APTOFI.COM attribution and https://aptofi.com as required by `LICENSE`.
